# Security

TuneForge's public deployment has undergone a dedicated pre-launch security review.

Detailed defensive controls, threat models, operational thresholds, and incident-response procedures are intentionally not documented in the public repository.

## Responsible disclosure

Please do not publish sensitive vulnerability details in a public GitHub issue.

If you believe you have found a security issue, contact the repository owner privately through the contact information linked from the GitHub profile.

## Sensitive data

Do not upload confidential, regulated, proprietary, personal, or credential-bearing data to a public TuneForge deployment.

## Secrets

Never commit credentials, API keys, provider tokens, private model URLs, or other production secrets to the repository.

## Scope

The public TuneForge deployment is a portfolio demonstration and self-hostable engineering reference. Organizations deploying TuneForge in a different environment are responsible for their own identity, access-control, infrastructure, data-governance, monitoring, and operational security requirements.
