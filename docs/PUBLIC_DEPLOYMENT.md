# Public Deployment

## Live production

- **Web:** https://tuneforge-algosphere1.vercel.app
- **API:** https://tuneforge-public-api.vercel.app
- **Repository:** https://github.com/mohit231007/TuneForge

TuneForge's public portfolio deployment is hosted on Vercel and is intentionally limited to the public demonstration experience.

## Product behavior

The public site exposes:

- verified Experiment 001 measurements
- experiment configuration surfaces
- adapter and comparison interfaces
- deterministic evaluation tooling
- system architecture documentation

Full self-service training remains available through the self-hosted TuneForge stack.

## Verification

The production deployment has completed the project's release QA and pre-launch security review.

Detailed defensive configuration is intentionally not documented in the public repository.
