# Resume Bullets

## Concise

Built **TuneForge**, a self-service LoRA/QLoRA LLM adaptation platform using PyTorch, Hugging Face Transformers, PEFT, TRL, FastAPI and Next.js, with GPU-aware fine-tuning, queued workers, telemetry, deterministic evaluation and versioned adapter lifecycle management.

## Evidence-led

Engineered an end-to-end PEFT platform that adapted TinyLlama-1.1B with ~1.13M trainable parameters (~0.10% of total) in the reference LoRA configuration; added reproducible data preparation, T4-safe FP16 training, QLoRA, experiment comparison, adapter persistence and measurable base-vs-adapted evaluation.

## Platform / MLOps emphasis

Designed TuneForge as an LLM engineering control plane separating Next.js UI, FastAPI orchestration, pluggable execution backends, queued CUDA workers, training telemetry, evaluation artifacts and governed adapter promotion (candidate → validated → production → archived).
